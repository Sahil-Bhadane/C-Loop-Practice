# C Loop Practice

A collection of C programs created while learning and practicing loops.

## Topics Covered

- while loop
- do-while loop
- for loop
- Loop conditions
- Counters and updates
- Repetition and iteration
- Combining loops with switch statements

## Programs

| Program | Concept |
|---|---|
| while_numbers.c | while loop |
| even_numbers.c | while loop with counter |
| do_while_menu.c | do-while + switch |
| for_numbers.c | for loop |

## Learning Purpose

These programs are part of my C programming practice, focusing on understanding loop logic and improving problem-solving skills.
